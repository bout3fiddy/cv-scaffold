# CV design

The starter includes three layouts: a standard CV with coloured emphasis and
skill tags, a strategy layout with right-aligned dates, and a compact
quantitative layout. All use JetBrains Mono and produce selectable text.

You can ask your agent to adjust typography, colour, spacing, headings or page
length. Supply a screenshot, document or Paper/Figma design as a reference.
The agent translates the design into the CV layout and checks every exported
page. Keep the fictional examples for early design experiments.

## Prompts to try

> Compare the three CV layouts using the same content. Show me the PDFs and
> explain how the spacing and hierarchy affect readability.

> Use this Paper or Figma frame as a reference for my CV. Keep my wording and
> contact links, match the typography and spacing, and show me the result.

> Make the CV easier to scan. Show me a version with clearer section headings
> and more space between roles while keeping it to two pages.

Design references and layout settings live in this folder. Your experience
and achievements stay in your profile and CV documents. Tell the agent which
version you prefer so it can record the choice.
