# Tailored applications

Use one directory per distinct role: `<organisation>--<role>/`. Copy an approved
master or reviewed draft, then tailor only relevant, verified facts.
Create `role.md` and `review.md` from the tracked templates. Store `resume.html`,
`cover-letter.md` and `outputs/` alongside them. Fix relative stylesheet links
when copying HTML; renderers still read the shared CSS in `design/cv/`.

Record the primary role URL or supplied brief and capture date. Distinguish
posting requirements from interpretation. Keep status `draft` until user
confirmation or a receipt establishes submission.
Record submission only from user confirmation or a receipt. Do not infer deadlines,
responses or employer consent. Retain the role record and supporting evidence when closing an application. Never edit a submitted version in place.

## Export commands

Use the explicit-source commands in `../personal/AGENTS.md`, replacing each
source and output path with the corresponding role folder. Pass the confirmed
candidate name, role and document title to the cover-letter builder. Validate
the actual role-specific files. Record validation and user approval in the
role's review file.
